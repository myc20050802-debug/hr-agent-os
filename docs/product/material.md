## 1. Overview

- **定位**：B 端 HR AI Agent 平台（招聘全链路），PoC → 可演示档；对外统一口径「本地全栈应用」。
- **核心命题**：把「AI 给的结论业务方不敢签字」变成「**每一个分数都能回答为什么**」。
- **目标用户**：中大型企业 HR 部门 / 招聘团队（私有化部署、数据不出境）。
- **Non-goals（明确不做）**：不做通用大模型、不做简历库买卖、不做面向 C 端的求职产品。
- **作者角色**：产品定义 + 口径设计 + 工程落地 + 自建评测，**独立完成**。

## 2. Background

- **起点**：HR 场景里 AI 落地真正难的不是「接一个大模型」，而是「**结论可被业务方签字**」。
- **演进**：PoC → v13 / v14 / v16 三轮口径修复 → 档位一致率 **90.0% → 96.7%**。
- **现状规模**：24 页面 · 47 后端接口 · schema v9 · 12 回归套件 · 约 19,400 行 JS · 10,300+ 行文档。
- **交付形态**：GitHub 开源（MIT 协议）+ 2 个在线演示（GitHub Pages / WorkBuddy 沙箱）+ 单文件作品集 HTML。

## 3. Key Info

- **运行时依赖 0**：Node 22 原生 `http` + 内置 `node:sqlite`（`dependencies` 为空，clone 下来一条命令起）。
- **权限真的在服务端**：24 能力 × 7 角色 + 行级数据范围（`all/dept/self`）+ PII 字段物理脱敏；越权是**真 403**。
- **审计改不掉**：应用层只插不改 + 数据库 `BEFORE UPDATE` / `BEFORE DELETE` 触发器 `RAISE(ABORT)`。
- **JD 接地真实市场 + 合规红线**：183 条市场岗位快照做「接地」，命中「35 岁以下」「仅限本地户口」类表述**直接阻止发布**。
- **分数 100% 由确定性规则算出**：可复现、可追溯；模型只做措辞与语言组织。

## 4. Evidence

- **评测（黄金集）**：30 例（3 岗位 × 各 10 例），**人工标注**、三档 `strong/ok/no`、口径 `rubricVersion=1`。
- **三个指标**：档位一致率 **96.7%**（29/30）· ±1 档一致率 **100%** · **漏筛 0.0%（红线）** · 误筛 8.3%。
- **统计诚实**：样本仅 30，同时给出 **Wilson 95% 置信区间 [83.3%, 99.4%]**。
- **门槛拦截**：年限 ×2 / 学历 ×1 / 技能零命中 ×6，共 **9 例**被硬性门槛拦下。
- **一次真实迭代**：改「判定链条」→ 一致率 90.0%→**96.7%**、误筛 25.0%→**8.3%**，同时**保住漏筛 0%**。
- **工程纪律**：12 回归套件 · 文档真相守卫 **25 处锚点** · **负向锚点** · `baseline.json` 评测单一源 · CI Node 22/24 双矩阵。
- **三次真实翻车**：①「测试全绿」其实是假的（页面 id 写死）②离线端与后端两套逻辑漂移 ③规则模式下却报了 token 与成本。
- **自审 12 项**（已修）：虚报模型调用与成本 · 「已进入优化数据集」是空话 · 一个死按钮 · WAL 从不 checkpoint · 无障碍为 0。

## 5. Analysis

- **与「长得像 HR 系统的演示原型」的区别**：原型是「点得动」，本项目是「**答得上**」——答得上分数怎么来的、为什么被拒、JD 为什么这么写。
- **规则 vs 模型的分工**：不是降级方案，是**设计选择**（可复现、可签字），见双模式对照评测。
- **业务取舍**：为守「漏筛 0%」红线，主动接受 8.3% 误筛 —— HR 场景里「错杀好简历」的代价远高于「多聊一轮」。
- **产品设计原则**：三个「必须」（可解释 / 可复现 / 留痕）+ 三个「不做」（不把判断权交给模型 / 不编硬数字 / 不让 AI 越过人工闸门）。

## 6. Outlook

- **扩样**：黄金集 30 → 60+，必须**独立标注**（不能拿规则输出当答案）；口径与 7 个决策已独立成文（`docs/20`）。
- **已知边界**：单租户 · 无真实简历入口 · 模型未接入默认链路 · 并发天花板未压到极限 · 无障碍仅最小集。
- **定位判断**：这些属「可信度打磨」，不是「升档必需」——项目已稳在 A 档（可演示档）。
